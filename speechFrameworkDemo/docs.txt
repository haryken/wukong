Summary
The skill control interface is the interface to provide quick calling skills through skill names.

These skills are designed and packaged to provide direct calls to third parties to improve development efficiency.

Skill Overview
What is Skill Skill is a defined component that represents the life cycle of a function. It is essentially an Android Service component.

How to customize Skill
create a java class extendsMiniMasterSkill, please refer to DemoSkill in the demo program
Define a configuration file The configuration file is in xmlformat and must be placed in theres/xml/directory of the Android Studio project.The format is as follows
<?xml version="1.0" encoding="utf-8"?>
<skill name="demo_skill">
    <call
        path="/demo/startSkill">
        <intent-filter category="speech">
            <utterance sentence="startSkill" />
        </intent-filter>
    </call>
</skill>

note: category must be assigned a value of "speech". Other values are not currently supported.

namerepresents the name of skill， represents the methods provided by this skill. A Skill can provide multiple methods. You can use path to define the method, or you can specify to specify. Call of Skill Skill call refers to calling a method in Skill. You can specify a path to call, or you can specify utterance to call. The sample code shown below is called by specifying utterance:
    public static void startThisSkill() {
        SkillHelper.startSkillByIntent("startSkill", null, new ResponseListener<Void>() {
            @Override
            public void onResponseSuccess(Void aVoid) {
                Log.d(TAG,"onResponseSuccess");
            }

            @Override
            public void onFailure(int i, @NonNull String s) {
                Log.d(TAG,"onFailure");
            }
        });
    }

Stop of Skill Exit can be achieved by calling Skill's default method inside the Skill class, or it can be called externally to exit. The method of exiting externally is shown below:
    public static void stopThisSkill() {
        Master.get().execute(DemoSkill.class, new ContextRunnable<DemoSkill>() {
            @Override
            public void run(DemoSkill skill) {
                skill.stopSkill(new Bundle());
            }
        });
    }
